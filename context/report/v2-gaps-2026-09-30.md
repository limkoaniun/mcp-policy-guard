### B3. §5, implementation facts not yet recorded
Four things §5 could carry in a sentence each:

- **The prompted baseline is a flag**, `--prompt told-the-rules`, on both
  campaign runners; the prompt text lives in `agent/prompts.py` and is
  recorded in each run's manifest, so Table 5 is reproducible from the same
  command as Table 1.
- **Attachment resolution by file name.** The first upload campaign was
  discarded because every model asked for the document by the name in the
  student's message rather than the scenario's id. §6.3 records the defect;
  §5 should record the fix: the server resolves either, and delivery is
  counted either way.
- **PDF handling in the demo.** pypdf extraction, a 2 MB size cap and a
  file-name length cap enforced before anything touches disk, a refusal with
  a reason when a PDF has no extractable text, and the extracted text served
  by `get_attachment` exactly as a scenario attachment would be.
- **Approval replay.** Because taint lives for one proxy process, Allow on
  the approval card re-issues the turn's untrusted reads and then the held
  call through a proxy in approve mode, so the demo never executes a call
  the proxy did not see. This is the concrete form of the §7 turn-boundary
  limitation and belongs beside it.
